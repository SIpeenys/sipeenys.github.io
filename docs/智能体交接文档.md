## 三、技术架构

```
用户写 md → D:\zsbsth（Hexo 源） → git push
  → GitHub Actions（.github/workflows/deploy-pages.yml）
  → 构建静态网页 → GitHub Pages 托管 → https://sipeenys.github.io
评论数据 → Supabase 云数据库（独立于 git）
统计 → 不蒜子（busuanzi）
```

**核心认知**：
- 博客 = 静态网站，push 时"烧制"好网页
- 评论 = 独立数据库，不走 git
- 一切以 **git push** 为触发点；本地没 push 的改动不会上线

## 四、评论区系统（重点！刚经历过两轮修复）

### 架构
- 前端组件：`source/comments/comments.js`（纯 JS + fetch 直连 Supabase REST API，无第三方依赖）
- 注入方式（Butterfly）：`themes/butterfly/_config.yml` 的 `inject.bottom` 里有一段脚本——检测文章页（`#article-container.post-content`）→ 创建评论容器 → 动态加载 comments.js
- 灰白配色样式：`source/css/butterfly-gray.css`（浅色 `:root` + 深色 `[data-theme='dark']` + 浅蓝 `#nav` + `sc-*` 评论区样式）

### 权限模型（审核模式）
- Supabase 建表 SQL：`supabase-schema.sql`（**触发器强制 status='pending'** + 插入策略放行 + 读取策略只显示 approved）
- 管理入口：Supabase 控制台 → Table Editor → `comments` 表 → status 改 `approved` 即显示
- 读取接口：`GET {project}/rest/v1/comments?...&status=eq.approved`（anon key）

### ⚠️ 刚修的两个 bug（务必记住，防止复发）
1. **`list.replaceChild(root, list.firstChild)` 在空列表时报错** → 改为"先 `while(list.firstChild) removeChild` 再 `appendChild`"
2. **`form.nick = nickInput` 报 "Named property setter is not supported"** —— HTMLFormElement 对已命名控件（输入框 name="nick"）的属性赋值会抛错，**导致 `load()` 从未执行、评论区空白** → 修复：全部改用闭包变量 `nickInput/mailInput/contentArea` 直接引用，不再往 form 上挂这些属性

**调试评论区三板斧**（以后出问题按此排查）：
1. `curl` 直连 Supabase API 看数据是否返回（确认后端）
2. 抓线上 HTML 看注入脚本和容器是否存在（确认前端挂载）
3. 让用户开无痕窗口 Ctrl+Shift+N（排除浏览器缓存——GitHub Pages 有 10 分钟 CDN 缓存）

## 六、日常操作（用户工作流）

1. 写文章：`hexo new 英文名` → 编辑 `source/_posts/xxx.md`（front-matter 写中文标题）
2. 用户喊"push 一下" → **先 `git status` 检查改动 → 确认没问题 → add/commit/push**
3. 改配置：改对应文件 → push
4. 评论审核：Supabase Table Editor → status 改 approved

> ⚠️ 用户不熟悉 git，所有命令代跑；push 前**务必先 `git diff` 检查**，防止误提交（曾发生过用户删文章被误提交）。

## 七、历史踩坑速查（下一位必须知道）

1. **vercel.app 国内 DNS 被污染**（face:b00c 特征）——国内用户无法直连；Vercel/CloudBase 方案已全部放弃
2. **Hexo 时区坑**：permalink 不要含日期（现用 `:title/`），否则 CI(UTC) 和本地(+8) 生成 URL 不一致
3. **NexT 7.8 与 Hexo 8 不兼容**（swig 已移除）——用 NexT v8（next-theme 仓库）；Butterfly 需 `hexo-renderer-pug`
4. **Windows curl 传 JSON**：PowerShell 引号会吞掉，用 `--data-binary @file.json`；TLS 报错加 `--ssl-no-revoke`
5. **npm install 30s 超时**：长命令用后台运行 + 日志轮询（`Start-Process` + `Start-Sleep`）
6. **Supabase RLS 调试**：`Prefer: return=representation` 头会导致 pending 行回读失败报 42501，客户端不带此头即可
7. **中文文件名文章 → 中文 URL**（能用但不美观），建议 `hexo new 英文名`
8. **`Select-String -SimpleMatch` 会把 `|` 当字面量**，正则需单独写
