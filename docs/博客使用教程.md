## 二、写一篇文章（核心流程）

### 第 1 步：打开终端，进入博客目录
```bash
cd D:\zsbsth
```

### 第 2 步：新建文章
```bash
hexo new hello-world
```
- 自动生成文件：`source/_posts/hello-world.md`
- ⚠️ **文件名建议用英文**（如 `hello-world`、`my-first-post`）
  - 网址 = 文件名，英文 URL 更美观、好分享
  - 中文标题写在 front-matter 的 `title` 里（下面会讲）

### 第 3 步：编辑文章（用 VS Code 打开这个 md 文件）

文章开头是 **front-matter**（配置区），照着填：

```markdown
---
title: 你好，世界            # 显示在网页上的标题（可中文）
date: 2026-08-09 12:00:00   # 日期时间
categories: [生活]           # 分类：技术 / 生活（可多个）
tags: [随笔, 夜记]          # 标签（可多个）
comments: true              # true=开评论区，false=关闭
---

正文从这里开始写...
```

### 第 4 步：插入图片（两种方式）

**方式 A：本地图片（推荐）**
1. 把图片放进 `source/images/` 文件夹
2. 文章里写：`![图片说明](/images/你的图片.png)`

**方式 B：网络图片**
直接粘贴图片 URL：
```
![图片说明](https://example.com/xxx.png)
```

> 图片文件名建议英文，避免特殊字符。

### 第 5 步：本地预览（推荐，先看效果再发布）
```bash
hexo server
```
浏览器打开 **http://localhost:4000** 预览 → 确认没问题后按 `Ctrl+C` 停止。

### 第 6 步：发布上线
```bash
git add -A
git commit -m "新文章：你好，世界"
git push
```
等 1~2 分钟，**https://sipeenys.github.io** 自动更新 ✅

## 三、修改 / 删除文章

| 操作 | 方法 |
|---|---|
| 修改文章 | 直接编辑 `source/_posts/xxx.md` → 然后 `git add -A && git commit -m "修改" && git push` |
| 修改标题/分类/标签 | 编辑文章开头的 front-matter |
| 删除文章 | 删除对应的 `.md` 文件 → 然后 push |
| 想暂停文章（不删） | 把文件名改成 `draft-xxx.md` 的草稿格式（不 push 即可） |

## 五、修改网页的样式 / 配置

### 常用文件位置

| 想改什么 | 文件 |
|---|---|
| 站点标题 / 描述 / 时区 | `_config.yml` |
| 主题外观（方案、菜单、头像） | `themes/butterfly/_config.yml` |
| **深灰配色（色值）** | `source/css/butterfly-gray.css` |
| 额外样式（评论区、滚动条） | `source/css/butterfly-gray.css` |
| 评论区逻辑 | `source/comments/comments.js` |

### 改站点信息（标题 / 副标题 / 描述 / 作者 / 页脚签名）

打开 `_config.yml` 最开头的 `# Site` 部分：

```yaml
# Site
title: 六便士的世界          # ① 网站标题（浏览器标签页、首页大标题）
subtitle: 认真生活，也认真写代码   # ② 副标题（标题下面那句话）
description: 一个记录技术学习与生活思考的个人博客  # ③ 站点描述（搜索引擎看到的简介）
author: SIpeenys            # ④ 作者名（页脚版权、文章作者用）
```

| 想改哪个 | 怎么改 |
|---|---|
| ① 标题 | 改 `title:` 后的文字 |
| ② 副标题 | 改 `subtitle:` 后的文字 |
| ③ 站点描述 | 改 `description:` 后的文字（就是你说的"一个记录技术学习与生活思考的个人博客"） |
| ④ 作者名 | 改 `author:` 后的名字（页脚"© 2026 作者名"会跟着变） |

> ⚠️ 修改后必须执行 `git push` 才会在线上生效。

页脚版权想写自定义文字（不只是作者名）的话，编辑 `themes/next/_config.yml` 的 `footer:` 部分：
```yaml
footer:
  since: 2026               # 起始年份
  copyright: 你的自定义文字   # 留空 = 用 author 名
```

### 例子：换颜色
打开 `source/_data/variables.styl`，改色值即可：
```styl
$body-bg-color    = #232529   // 页面背景
$text-color       = #cfd3d8   // 正文文字
$content-bg-color = #2b2d31   // 卡片背景
```
改完 `git push` 就会自动上线。

> ⚠️ 改配置后建议先 `hexo server` 预览确认没问题，再 push。

## 六、添加新页面（如"友链"页）

```bash
hexo new page links
```
- 生成 `source/links/index.md`，编辑内容即可
- 想让它在顶部导航出现：编辑 `themes/next/_config.yml`，在 `menu:` 里加一行：
  ```yaml
  links: /links/ || fa fa-link
  ```
- push 后生效

## 七、评论区管理（Supabase）

访客留言后会进入「待审核」，需要你手动通过：

1. 打开 **https://supabase.com/dashboard/project/mxurcwwkezdpyjmjqkmi**
2. 左侧菜单 → **Table Editor**（表格编辑器）→ 找到 `comments` 表
3. 操作：
   - **通过显示**：把 `status` 从 `pending` 改成 `approved`
   - **删除**：选中行 → 点删除按钮

> 评论数据存在 Supabase 数据库里，和 git 无关，只在这里管理。

## 十一、常见问题 FAQ

**Q：改了文章但网上没变化？**
检查是否执行了 `git push`，且等待 1~2 分钟（Actions 在跑）。也可以在 GitHub 仓库的 Actions 页面看构建是否成功。

**Q：本地预览和线上不一样？**
以 push 为准。本地没 push 的改动不会上线。

**Q：`hexo new` 后文件名是中文的，网址难看怎么办？**
用英文建文章：`hexo new my-post`，再把中文标题写进 front-matter 的 `title`。

**Q：文章里的日期不对？**
网址不包含日期（用的是 `:title/`），显示的日期来自 front-matter 里的 `date`。

**Q：图片不显示？**
本地图片必须放在 `source/images/` 下，且路径写 `/images/文件名`（开头有斜杠）。

**Q：评论区加载不出来？**
Supabase 是国外服务器，偶尔慢或抽风——刷新一下，或稍后再试。博客内容本身不受影响。

**Q：文章想改分类/标签？**
直接编辑文章开头的 front-matter（categories / tags），push 即可。
