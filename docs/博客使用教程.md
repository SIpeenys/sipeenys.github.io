## 二、写一篇文章（核心流程）

### 第 1 步：打开终端并进入博客目录
```bash
cd D:\zsbsth
```

### 第 2 步：新建文章
```bash
hexo new "文章标题"
```
会自动生成文件：`source\_posts\文章标题.md`

### 第 3 步：编辑文章（用 VS Code 打开这个 md 文件）

文章开头是 **front-matter**（配置区），照着填：

```markdown
---
title: 文章标题              # 显示在网页上的标题
date: 2026-08-09 12:00:00   # 日期
categories: [技术]           # 分类：技术 / 生活
tags: [Hexo, 笔记]          # 标签（可多个）
comments: true              # true=开评论区，false=关
---

正文从这里开始写...
```

### 第 4 步：本地预览（可选，推荐先看效果）
```bash
hexo server
```
浏览器打开 **http://localhost:4000** 预览 → 看完按 `Ctrl+C` 停止。

### 第 5 步：发布上线
```bash
git add -A
git commit -m "新文章：xxx"
git push
```
等 1~2 分钟，**https://sipeenys.github.io** 自动更新 ✅

## 四、修改网页的样式/配置

### 常用文件位置

| 想改什么 | 文件 |
|---|---|
| 站点标题/描述/时区 | `_config.yml` |
| 主题外观（方案、菜单、头像） | `themes/next/_config.yml` |
| **深灰配色（色值）** | `source/_data/variables.styl` |
| 额外样式（评论区、滚动条） | `source/_data/styles.styl` |
| 评论区逻辑 | `source/comments/comments.js` |

### 例子：换颜色
打开 `source/_data/variables.styl`，改色值即可：
```styl
$body-bg-color    = #232529   // 页面背景
$text-color       = #cfd3d8   // 正文文字
$content-bg-color = #2b2d31   // 卡片背景
```
改完 `git push` 就会自动上线。

> ⚠️ 改配置后建议先 `hexo server` 预览确认没问题，再 push。

## 五、评论区管理（Supabase）

访客留言后会进入「待审核」，需要你手动通过：

1. 打开 **https://supabase.com/dashboard/project/mxurcwwkezdpyjmjqkmi**
2. 左侧菜单 → **Table Editor**（表格编辑器）→ 找到 `comments` 表
3. 操作：
   - **通过显示**：把 `status` 从 `pending` 改成 `approved`
   - **删除**：选中行 → 点删除按钮

> 评论数据存在 Supabase 数据库里，和 git 无关，只在这里管理。

## 七、常见问题 FAQ

**Q：改了文章但网上没变化？**
检查是否执行了 `git push`，且等待 1~2 分钟（Actions 在跑）。

**Q：本地预览和线上不一样？**
以 push 为准。本地没 push 的改动不会上线。

**Q：文章里的日期不对？**
注意 URL 不包含日期（用的是 `:title/`），显示日期来自 front-matter 里的 `date`。

**Q：评论区加载不出来？**
Supabase 是国外服务器，偶尔慢或抽风——刷新一下，或稍后再试。博客内容本身不受影响。

**Q：文章想改分类/标签？**
直接编辑文章开头的 front-matter（categories / tags），push 即可。
