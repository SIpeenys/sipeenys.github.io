# 「六便士的世界」博客功能一览

> 本文档罗列博客当前所有功能、实现方式及管理入口，方便你全面了解自己的站点能力。

---

## 一、核心功能

| 功能 | 实现 | 说明 |
|---|---|---|
| **文章发布** | Hexo + Markdown | 本地写 md 文件，push 自动上线 |
| **分类 / 标签** | Hexo front-matter | 支持一篇文章多个分类和标签 |
| **归档** | Hexo 生成 | 按年份自动归档所有文章 |
| **独立页面** | Hexo page | 关于我 / 标签 / 分类 / 友链等 |
| **本地预览** | `hexo server` | 浏览器打开 localhost:4000 预览 |

## 二、主题外观

| 功能 | 实现 | 说明 |
|---|---|---|
| **Butterfly 主题** | v5.7.0（Hexo 官方最火的主题之一） | 卡片式布局、现代设计 |
| **灰白配色** | 自定义 CSS 变量覆盖 | 页面 #f2f4f6 / 卡片 #ffffff / 文字 #3f444b |
| **顶部导航** | `#nav` 深蓝背景 | 亮/暗模式一致为深海洋蓝 #28547a，白色文字 |
| **深色模式** | `[data-theme='dark']` 变量保留 + `display_mode: light` | 默认浅色，暗色配色随时可改回 |
| **代码高亮** | darker 主题 + 一键复制 | 深色背景 + 语法高亮 |
| **文章字数 / 阅读时长** | hexo-wordcount 插件 | 文章页显示本文字数 + 预计阅读时长 |
| **全站总字数** | 侧边栏「网站信息」卡片 | 首页统计卡显示本站总字数 |
| **音乐播放器** | 自建悬浮播放器（`source/music/music.js`） | 主页/单篇文章可设音乐，左下角播放 |
| **响应式设计** | 主题自带 | 手机/平板/电脑自动适配 |
| **返回顶部** | 主题自带 | 右下角按钮 + 阅读进度百分比 |

## 三、评论区（Supabase）

| 功能 | 说明 |
|---|---|
| **匿名留言** | 访客只需填昵称即可留言，无需任何登录 |
| **审核模式** | 留言提交后进入 pending 状态，需你在 Supabase 控制台手动批准 |
| **回复功能** | 支持楼中楼回复 |
| **防 XSS** | 评论内容纯文本渲染，防注入攻击 |
| **客户端限流** | 15 秒内不允许重复提交 |
| **管理员入口** | Supabase 控制台 → Table Editor → comments 表（改 status 通过/删除） |
| **管理后台** | `/admin/` 页面 + Supabase Auth 登录 | 网页上一键审核/删除评论 |
| **零成本** | Supabase 免费版（500MB 数据库 ≈ 50 万条评论） |

## 四、搜索与订阅

| 功能 | 实现 | 说明 |
|---|---|---|
| **本地搜索** | hexo-generator-searchdb | 右上角放大镜，实时搜索文章标题和内容 |
| **RSS 订阅** | hexo-generator-feed | `/atom.xml`，可通过 RSS 阅读器订阅博客 |

## 五、统计与 SEO

| 功能 | 实现 | 说明 |
|---|---|---|
| **全站访客统计** | 不蒜子（busuanzi） | 首页底部显示全站访客数（UV）和浏览量（PV） |
| **文章浏览量** | 不蒜子 | 每篇文章标题下方显示阅读次数 |
| **站点 SEO 描述** | `description` 配置 | 搜索引擎看到的博客简介 |
| **关键词** | `keywords` 配置 | 搜索引擎优化 |

## 六、部署与托管

| 项目 | 说明 |
|---|---|
| **托管平台** | Cloudflare Pages（免费，全球 CDN，国内访问流畅） |
| **自动部署** | GitHub Actions（每次 push 自动构建发布，1~2 分钟） |
| **版本控制** | Git + GitHub（所有改动可追溯、可回滚） |
| **双主题备份** | themes/next 和 themes/butterfly 同时保留，一键切换 |

## 七、侧边栏组件

| 组件 | 内容 |

| **标签/分类** | 显示所有标签和分类 |
